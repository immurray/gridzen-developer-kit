# Public UI languages

The hosted developer interface supports English, Spanish, Simplified Chinese and Vietnamese. Language changes never enable live providers, billing or country coverage. API identifiers, code and original research evidence retain their source representation. Vietnamese copy was machine translated and structurally checked; native-language certification is not claimed.

The shared website shell defines navigation. UI dictionaries must preserve placeholders and limitations. Locale keys come from the available dictionaries; a missing dictionary must not be advertised as a translated interface. Source changes require regeneration and review before publication. The main GridZen repository owns the versioned translation source and build_public_locale_assets.py; this repository contains generated public UI assets only, with no credentials.
