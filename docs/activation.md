# From installation to first use

```sh
python3 -m venv .venv
.venv/bin/pip install gridzen-developer-kit
.venv/bin/gridzen start --task identity_onboarding --lang en
```

1. Run the anonymous synthetic trial for success, rejection and unavailable outcomes.
2. Register and verify your email only when you need persistent sandbox records.
3. In Console, run a new sandbox request. Identity sessions require the available provider sandbox; the phone adapter is synthetic.
4. Optionally consent to account/project progress measurement, then complete a new request on a different UTC day. Polling an old record is not reuse.
5. The Console TEST wallet demonstrates orders, debit, refund and reconciliation with simulated credits. It never charges money or enables production.

Source categories are user-confirmed, not verified acquisition attribution. Linked measurement expires after 90 days and can be withdrawn/deleted without losing service. A separate reminder subscription is available only after the independent customer mailbox passes acceptance; at most two emails, at least 72 hours apart. Reply, activation or unsubscribe stops it.

Do not put customer keys, real documents or conversations into marketing prompts. The five research/synthetic MCP tools and six Skills retain their existing boundaries. Production access, provider rights and prices require a separate review.
