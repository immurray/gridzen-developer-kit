# Harness installation

Use Python 3.11+, a virtual environment and `gridzen setup --client CLIENT --project .`.
Preview first, add `--apply` to write. `--client all` prepares all ten clients in one
project. Native activation still requires workspace trust/restart. Desktop and
Cline MCP configurations are manual imports; generated files alone do not enable
them. See each client guide and [actual acceptance](../../clients/compatibility.json).
