# Explain a check result

Turn a documented status into a clear recovery step without sending a new request.

Install this whole directory as `gridzen-result-explanation` or use `gridzen setup --client <client> --product result-explanation --project . --apply`. Preview by omitting `--apply`.

Version 1.0.0 · MIT. [Product](https://gridzen.ai/tools/result-explanation/). Explanations do not change the provider result, issue a compliance conclusion or authorize a retry, payment or business approval.
