# Check a SPEI payment

Retrieve the CEP for an authorized existing payment and inspect its signature and transaction binding.

Install this whole directory as `gridzen-mx-cep` or use `gridzen setup --client <client> --product mx-cep --project . --apply`. Preview by omitting `--apply`.

Version 1.0.0 · MIT. [Product](https://gridzen.ai/tools/mx-cep/). Does not initiate a transfer or prove present account control, identity or a safe payout. Source access restrictions can delay a task.
