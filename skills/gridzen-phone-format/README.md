# Clean phone formatting

Remove presentation separators from an international number and check E.164-shaped syntax locally.

Install this whole directory as `gridzen-phone-format` or use `gridzen setup --client <client> --product phone-format --project . --apply`. Preview by omitting `--apply`.

Version 1.0.0 · MIT. [Product](https://gridzen.ai/tools/phone-format/). Structure-only local utility. No network, OTP, lookup billing or claim that the number exists.
