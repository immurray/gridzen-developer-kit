# Compare identity and account

Submit authorized CURP and CLABE for one identity and beneficiary-account comparison, with a bound quote.

Install this whole directory as `gridzen-mx-identity-account` or use `gridzen setup --client <client> --product mx-identity-account --project . --apply`. Preview by omitting `--apply`.

Version 1.0.0 · MIT. [Product](https://gridzen.ai/tools/mx-identity-account/). No unconditional approval or arbitrary person lookup. No direct bank-CURP identifier claim, unsupported card input or transfer without the quote's explicit authorization.
