# Check CLABE formatting

Check an 18-digit CLABE checksum locally before starting an account verification.

Install this whole directory as `gridzen-clabe-format` or use `gridzen setup --client <client> --product clabe-format --project . --apply`. Preview by omitting `--apply`.

Version 1.0.0 · MIT. [Product](https://gridzen.ai/tools/clabe-format/). A correct checksum does not prove that an account exists, can receive funds or belongs to a person.
