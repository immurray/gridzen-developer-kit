# Start hosted identity

Create a hosted verification link and retrieve its authoritative result after the person completes the journey.

Install this whole directory as `gridzen-hosted-identity` or use `gridzen setup --client <client> --product hosted-identity --project . --apply`. Preview by omitting `--apply`.

Version 1.0.0 · MIT. [Product](https://gridzen.ai/tools/hosted-identity/). The person completes identity and liveness steps. New-person full approval acceptance remains pending; online purchases require payment-channel acceptance.
