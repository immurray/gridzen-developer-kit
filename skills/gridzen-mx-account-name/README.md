# Match a CLABE name

Compare an expected beneficiary name with supported bank evidence for one authorized CLABE.

Install this whole directory as `gridzen-mx-account-name` or use `gridzen setup --client <client> --product mx-account-name --project . --apply`. Preview by omitting `--apply`.

Version 1.0.0 · MIT. [Product](https://gridzen.ai/tools/mx-account-name/). A quoted microtransfer may apply and requires explicit recipient and spending authority. This is not document identity or proof of current account control.
