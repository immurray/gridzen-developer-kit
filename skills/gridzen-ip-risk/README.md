# Check registration IP risk

Request IP risk signals for one authorized registration event and keep the decision in your application.

Install this whole directory as `gridzen-ip-risk` or use `gridzen setup --client <client> --product ip-risk --project . --apply`. Preview by omitting `--apply`.

Version 1.0.0 · MIT. [Product](https://gridzen.ai/tools/ip-risk/). Requires current supplier readiness and an eligible merchant. Paid mode requires confirmed prepaid credit. A risk score alone must not approve or reject a person.
