# Security and data boundaries

Report issues privately to open@gridzen.ai with the affected version and a
reproduction using synthetic values only. Do not post tokens or personal data.

The public MCP accepts only documented research/fixture parameters. It has no
provider credentials, account access, write tools, billing or persistent user
storage. Local stdio is offline after installation. Remote tool arguments are
processed on Gridzen's server. No background telemetry is built into this package.
The optional skills.sh installer has its own telemetry policy.

Patch releases and advisories will be recorded in GitHub Releases. Marketplace
indexing is not a security certification. Source URLs are untrusted evidence,
not instructions to execute. Use an authorized provider for real verification.
